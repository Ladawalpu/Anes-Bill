# AnesBill: คู่มือติดตั้ง

ระบบนี้มี 2 ส่วน
- **แอป (PWA):** `index.html`, `manifest.json`, `sw.js`, `icon-192.png`, `icon-512.png` วางบน GitHub Pages
- **ที่เก็บข้อมูล:** `Code.gs` วางใน Google Sheet (Apps Script)

## 1. ตั้งค่า Google Sheet + Apps Script (ทำครั้งเดียว)
1. สร้าง Google Sheet ใหม่ ตั้งชื่อ เช่น `AnesBill Data`
2. ไปที่ **ส่วนขยาย (Extensions) → Apps Script** ลบโค้ดเดิมออก แล้ววางเนื้อหา `Code.gs` ทั้งไฟล์ จากนั้นกดบันทึก
3. เลือกฟังก์ชัน `setup` แล้วกด **Run** และกดอนุญาตสิทธิ์ ระบบจะสร้างชีต `Cases`, `Items` (188 รายการ) และ `Rooms` (22 จุด)
4. ไปที่ **Project Settings (รูปเฟือง) → Script properties** แล้วเพิ่ม 2 ค่านี้
   - `APP_PIN` คือรหัสทีมที่ทุกคนใช้ เช่น `4821`
   - `ADMIN_PIN` คือรหัสผู้ดูแล ใช้ตอนล้างข้อมูลรายเดือน
5. ไปที่ **Deploy → New deployment → Web app** แล้วตั้งค่า
   - Execute as: **Me**
   - Who has access: **Anyone**
6. คัดลอก URL ที่ลงท้ายด้วย `/exec`

> แก้ `Code.gs` ภายหลัง: ไปที่ Deploy → Manage deployments → ✏️ → Version: **New version** URL จะยังเป็นอันเดิม

## 2. วางแอปบน GitHub Pages
1. เปิด `index.html` หาบรรทัด `API_URL: ""` แล้ววาง URL `/exec` ลงในเครื่องหมายคำพูด
2. อัปโหลด 5 ไฟล์ของแอปขึ้น repo (จะสร้าง repo ใหม่ หรือใช้โฟลเดอร์ใน repo AnesHub เดิมก็ได้) แล้วเปิด GitHub Pages
3. เปิดลิงก์ แล้วกดปุ่มชื่อมุมขวาบน ใส่ **ชื่อ**, **จุดประจำ** และ **รหัสทีม (APP PIN)**
4. บนมือถือ กด "เพิ่มไปยังหน้าจอหลัก" เพื่อใช้งานเหมือนแอป

## 3. การใช้งานประจำวัน
| ใคร | ทำอะไร |
|---|---|
| วิสัญญีพยาบาลประจำห้อง | แท็บ **ส่งรายการ**: เลือกจุด กรอก HN และชนิดการระงับความรู้สึก ใส่เวลาเริ่ม/สิ้นสุด (ค่าบริการตามเวลาคิดให้อัตโนมัติ) เลือกยาและอุปกรณ์ แล้วกด **ตรวจและส่ง** |
| | แท็บ **เคสของห้อง**: ดูสถานะ แก้ไขเคสที่ถูกส่งกลับ, **ส่งรายการเพิ่ม** (กรณีลืม) หรือ **ยกเลิกเคส** |
| ผู้คีย์ (คอมหน้าห้อง) | แท็บ **ผู้คีย์**: เลือกเคส → **เริ่มคีย์** → คีย์ลง HosXP ตามลำดับ ติ๊กทีละบรรทัด (ปุ่ม copy คัดลอกรหัส) → **คีย์เสร็จ** ถ้าข้อมูลไม่ชัด กด **ส่งกลับแก้ไข** พร้อมเหตุผล |
| หัวหน้า/ผู้ดูแล | แท็บ **สรุป**: ดูยอดของแต่ละจุด / รอคีย์ / ส่งกลับ / คีย์แล้ว |

ช่องเวลาพิมพ์เป็นตัวเลข 4 หลักได้เลย เช่น `0900` หรือ `1345` แอปจะจัดรูปแบบเป็น 09:00 แล้วกระโดดไปช่องสิ้นสุดให้ (พิมพ์ `930`, `9.30` หรือ `9:30` ก็ได้ ถ้าเคสข้ามเที่ยงคืน เช่น 2300–0130 แอปคิดเวลาให้ถูกต้อง)

สถานะเคส: 🟡 รอคีย์ → 🔵 กำลังคีย์ → 🟢 คีย์แล้ว (หรือ 🔴 ส่งกลับแก้ไข → ผู้ส่งแก้ → กลับเป็นรอคีย์)

## 4. สิ้นเดือน
แท็บ **สรุป / ส่งออก** → เลือกเดือน → **ดาวน์โหลด Excel** (มี 3 ชีต: เคส, รายการ, สรุปรายจุด) → เก็บไฟล์ไว้ → **ล้างข้อมูลเดือนนี้** (ต้องพิมพ์เดือนและใส่ ADMIN PIN)

## 5. แก้รายการยา/อุปกรณ์ หรือจุดบริการ
แก้ในชีต `Items` / `Rooms` ได้เลย ไม่ต้องแก้โค้ด แอปจะโหลดรายการใหม่เมื่อเปิดครั้งถัดไป
- เพิ่มรายการ: เพิ่มแถวใหม่ โดยคอลัมน์ id ต้องไม่ซ้ำกับแถวอื่น เช่น `n1`, `n2`
- ซ่อนรายการ: ใส่ `N` ในคอลัมน์ "ใช้งาน"
- **ห้ามแก้ id ของรายการเดิม** และห้ามแก้รหัส `70 110`–`70 301` เพราะใช้ในการคิดค่าบริการตามเวลา

## 6. กติกาคิดค่าบริการตามเวลา (แก้ได้ที่ `ANES` ใน index.html)
| ชนิด | คิดอะไร |
|---|---|
| GA ทั่วไป | 70 110 ×1 + 70 111 × (นาทีที่เกิน 60 ÷ 15 ปัดขึ้น) + Volatile 70 201 × ชม. (ปัดขึ้น) + CO2 70 301 ×1 + เครื่องวัดความเข้มข้นยาดมสลบ 70 310 ×1 + Warmer 52 013 ×1 |
| GA ซับซ้อน | 70 112 / 70 113 แบบเดียวกัน + Volatile + CO2 + 70 310 + Warmer |
| RA | 70 130 ×1 + 70 131 × (เกิน 60 นาที ÷ 15 ปัดขึ้น) + Warmer 52 013 ×1 |
| TIVA | 70 120 × ชม. (ปัดขึ้น) + Warmer 52 013 ×1 |
| LA with MAC | 70 140 ×1 |

ตัวอย่าง: GA 08:00–11:00 คือเกินชั่วโมงแรก 120 นาที จึงได้ 70 111 = 8
CO2, 70 310 และ Warmer ใส่ให้ทันทีที่เลือกชนิด ส่วนรายการที่คิดจากเวลาจะขึ้นหลังกรอกเวลา
